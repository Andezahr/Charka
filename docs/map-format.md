# Текстовая карта Charka (`.map.txt`)

Карту боя можно нарисовать символами в любом текстовом редакторе (или попросить у ИИ), загрузить на странице «Карты» → «Загрузить карту» и выгрузить обратно кнопкой «⇩ Текстом» в редакторе карты. Файл в `src/main/resources/maps/` сразу становится шаблоном в списке «Сгенерировать» у всех кампаний (код шаблона — имя файла).

Код — `app.charka.map.MapText` (`parse` и `write`), примеры — `src/main/resources/maps/nightclub.map.txt` и тест `MapTextTest`.

## Пример

```
# комментарий
name: Бар «Ржавчина»
size: 6x2
cell: 2
legend:
  Q = tree
  edge Z = cover_stone
labels:
  a: Стойка
  0,0: Подпись по координатам
map:
+-+-+-+-+-+-+
|. . . . a .|
+ +D+-+ + + +
|P|. R R R R=
+-+-+-+-+-+-+
```

## Заголовок

| Ключ | Что | По умолчанию |
|---|---|---|
| `name:` | название карты | имя файла |
| `size: 70x50` | ширина × высота в клетках; строки рисунка длиннее — ошибка, короче — дополняются пустотой | по самой длинной строке и числу строк |
| `cell: 2` | метров в клетке | клетка системы (CP2020 — 2 м) |
| `legend:` | свои символы (ниже) | |
| `labels:` | подписи (ниже) | |
| `map:` | всё после этой строки — рисунок | обязателен |

Строки с `#` в начале до `map:` — комментарии; в легенде комментарий можно поставить и в конце строки (` # …`).

## Рисунок

Сетка двойная. Клетка `(x, y)` — символ в строке рисунка `2y+1` и столбце `2x+1` (считая с нуля): **клетки стоят на нечётных местах, стены — между ними**.

- Чётная строка — горизонтальные стены: символ в столбце `2x+1` — верхняя грань клетки `(x, y)`.
- Нечётная строка — клетки и вертикальные стены: символ в столбце `2x` — левая грань клетки `(x, y)`.
- Чётная строка и чётный столбец — угол: он только для глаза, его можно оставить пробелом или поставить `+`.

Поэтому пол рисуется точками через пробел (`. . . .`), а предмет — своей буквой в каждой клетке через пробел (`R R R R` — стойка бара 4×1). Табуляция запрещена: столбцы съедут.

### Стены (места между клетками)

| Символ | Что |
|---|---|
| пробел | ничего |
| `-` `\|` `+` | стена комнаты (CP2020: кирпич SP 25) |
| `:` `!` | перегородка (CP2020: гипсокартон SP 5) |
| `#` | бетон (CP2020: блочная стена SP 10; у системы без бетона — стена комнаты) |
| `D` / `d` | дверь закрытая / открытая |
| `S` / `s` | стальная дверь закрытая / открытая |
| `=` `W` | окно |
| `o` | проём (в парапете крыши: видно и перепрыгивают) |

### Клетки

| Символ | Что | Размер, клеток |
|---|---|---|
| `.` или пробел | пол | |
| `,` | асфальт | |
| `"` | газон | |
| `~` | вода | |
| `%` | обломки (трудная местность: бег вдвое дороже) | |
| `*` | дым: закрывает взгляд, стреляют вслепую | |
| `C` | машина (моторный конец сверху) | 2×4 |
| `A` | бронемашина | 2×4 |
| `X` | ящик | 1×1 |
| `B` | мусорный бак | 2×1 |
| `I` | столб | 1×1 |
| `T` | дерево | 1×1 |
| `$` | DataTerm | 1×1 |
| `M` | почтовый ящик | 1×1 |
| `H` | гидрант | 1×1 |
| `R` | стойка бара | 4×1 |
| `K` | стол | 2×1 |
| `L` | стеллаж | 3×1 |
| `U` | контейнер | 3×1 |
| `F` | бочка с горючим: взрывается | 1×1 |
| `G` | газовый баллон: взрывается | 1×1 |
| `^` | лестница: на соседнем уровне в той же клетке тоже `^` (M-22) | |
| `#` | пустота: пола нет, внизу виден нижний уровень, встать нельзя (M-22) | |
| `P` | зона старта игроков | |
| `N` | зона старта NPC | |

Предмет занимает свой прямоугольник целиком. Клетки одной буквы раскладываются на предметы слева направо и сверху вниз: сначала в том виде, как предмет описан (машина 2 в ширину и 4 в высоту), если не помещается — повёрнутым на четверть. Четыре клетки `C` в ряд и две строки — машина поперёк. Две машины бок о бок (4×4) разложатся вдоль; если важно иначе — оставьте между ними пустую клетку.

Под предметом, зоной и подписью местность — как у ближайшей обычной клетки слева в том же ряду (если там пол — пол), иначе справа: машина на дороге стоит на асфальте, хотя асфальт под ней не нарисован.

Зона — связные клетки `P` (или `N`); неровная дополняется до охватывающего прямоугольника с предупреждением.

### Своя легенда

```
legend:
  Q = tree               # клетка: код предмета или материала системы, floor, players, npcs
  edge Z = cover_stone   # грань: материал (стена, дверь или окно — по слою материала),
  edge G = door:cover_heavy_door:open   #   значение грани как есть,
  edge V = heavy_door    #   или инструмент: room, wall, door, heavy_door, window; gap, none
```

Своя легенда сильнее умолчаний. Для запасных вариантов — `?`: `cover_block?room` (бетон, а если у системы его нет — стена комнаты).

### Подписи

```
labels:
  a: Склад          # метка: символ «a» в клетке рисунка ставит подпись (меток может быть несколько)
  12,7: Касса       # подпись в клетке x=12, y=7
```

Метка сильнее легенды клеток, поэтому для меток удобны строчные буквы и цифры — в легенде по умолчанию их нет. Подпись — до 40 символов.

## Проверка

Ошибка останавливает загрузку и называет строку и столбец файла:

- символ клетки на месте стены и наоборот — почти всегда пропущенный или лишний символ, «съехал столбец»;
- буква предмета не закрывает его целиком;
- строка длиннее заданной ширины, рисунок больше высоты.

Предупреждения загрузку не останавливают (видны над редактором):

- ряд клеток короче или длиннее большинства — проверьте, не пропущена ли клетка; всё правее неё сдвинулось. Если ряд короче законно (пол нарисован пробелами), предупреждение можно не слушать;
- предмета или материала нет у системы кампании — клетки становятся полом;
- предмет разрезан стеной.

Нарисованный файл в `maps/` проверяет тест `MapTextTest.Drawn.files`: без предупреждений, есть обе зоны, от игроков до NPC можно дойти (двери открываются).

## Уровни (этажи, балкон, крыша)

Каждый раздел `map:` — уровень, снизу вверх, все одного размера (размер — у нижнего): `map: 0 Двор`, `map: 1 Балкон`, `map: 2 Крыша z=7`. Число — для глаза, название — на вкладке уровня, `z=` — высота пола в метрах (по умолчанию 3 м на этаж). Плоская карта — один раздел `map:` без номера.

- Лестница — `^` в одной и той же клетке на двух соседних уровнях. Фишка на лестнице поднимается кнопкой «⇡ 2 этаж»; это стоит вдвое больше высоты в метрах бега (3 м этажа — 6 м, хоумбрю).
- Пустота `#` на верхнем уровне — двор под балконом, проём в полу, улица под крышей. Сквозь неё видно и стреляют вниз и вверх; укрытие цели внизу не мешает тому, кто стреляет сверху (с. 103). Под полом верхнего уровня (не `#`) нижний не виден.
- Зоны старта — только на нижнем уровне. Подписи координатами (`5,3: текст`) — тоже нижнего; на верхних — меткой в рисунке.
- Взрыв и шальная пуля не проходят сквозь перекрытия: только свой уровень.

```
map: 0 Двор
+-+-+-+-+
|^ . . .|
+ + + + +
|P . . N|
+-+-+-+-+
map: 1 Балкон
+-+-+-+-+
|^ . # #|
+ + + + +
|. . # #|
+-+-+-+-+
```

## Как рисовать большую карту

1. Сначала план в клетках: где стены (номера граней), двери, зоны, крупные предметы.
2. Ряд за рядом: для каждого ряда клеток — строка граней над ним и строка клеток. Строка клеток полной ширины — `2·ширина` символов (с правой стеной `2·ширина+1`); одинаковая длина рядов — первая проверка.
3. Вертикальная стена стоит в одном и том же столбце во всех рядах — её видно глазом сверху вниз.
4. Загрузить, посмотреть в редакторе, поправить там или в тексте; «⇩ Текстом» выгружает карту обратно в этот формат.

Не сохраняются в тексте: подложка (картинка) и поворот предмета на пол-оборота (машина моторным концом вниз станет моторным концом вверх).
