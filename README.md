# Charka

**Менеджер персонажей для настольных ролевых игр** — кампании, персонажи, раны, инвентарь, деньги, заметки, счётчики, кубики и игровой календарь в одном веб-приложении для ведущего и игроков.

*A web app for tabletop RPG game masters and players: campaigns, characters, health, inventory, money, notes, dice and an in-game calendar. Interface is in Russian.*

## Возможности

Charka строится как **мультисистемный** менеджер: общее ядро плюс правила конкретных НРИ, которые подключаются к кампании.

| Система | Статус |
|---|---|
| **Cyberpunk 2020** (`CP2020`) | основная, в активной разработке |
| **Generic** (`GENERIC`) | универсальная — только ядро без правил системы |
| **D&D 5e** (`DND5E`) | запланирована: выжимка правил SRD 5.1 готова (`RULES_DND5E.md`) |

### Ядро (для любой системы)

- **Создание персонажа по правилам** (CP2020): очки 9D10, быстрым способом или кинематографично, статы с производными, роль и карьерный пакет на 40 очков, хобби на REF + INT, стартовые деньги по таблице занятий, лайфпас с событиями по годам в заметки.
- **Кампании** с выбором игровой системы и собственным игровым календарём; мастер начисляет опыт и IP всем игрокам одним нажатием.
- **Время кампании** — «время летит…»: промотка на N дней создаёт запись в хронике, сдвигает текущую дату и запускает правила системы (например, естественное лечение).
- **Персонажи** — лист по эскизу автора: сверху здоровье, броня и статы строками (урон наносится оттуда, журнал здоровья раскрывается там же), под ними основное оружие с итогом броска атаки («Пистолеты 5 + REF 6 = 11») и магазинами, запасное свёрнуто. Справа — деньги кратко, носимые инвентари, киберware фишками и «Частые навыки»: проверка одним нажатием, навыки закрепляются звёздочкой.
- **Навигация** — крошка «Кампания ▾ › Персонаж ▾» (переход к другому персонажу сохраняет вкладку), вкладки кампании и персонажа «Лист · Навыки · Снаряжение · Заметки»; «💬 Стол» — чат, кубики и проверка одной панелью с любой страницы.
- **Снаряжение** — отдельная вкладка: все инвентари, в том числе неносимые («В машине», «В нычке» — на листе их нет), полный журнал денег, регулярные траты, вживлённое.
- **Инвентари и предметы** — несколько инвентарей на персонажа, секции по типам, окно добавления со вкладками и поиском по справочнику, одинаковые предметы складываются, количество меняется кнопками. Галочка «Купить» списывает цену с денег персонажа. Магазины и патроны показаны под оружием: одно нажатие перезаряжает.
- **Деньги** — журнал операций по игровой дате, баланс считается из журнала, регулярные траты (аренда, еда; в CP2020 — шаблоны книги с зонами города) списываются сами при промотке времени; валюта зависит от системы (эдди в CP2020).
- **Заметки** с категориями (у каждого персонажа свои) и фильтром; **контакты** — кто это, как относится, кто кому должен.
- **Временные эффекты** — правка стата со сроком в раундах, часах или днях: раунды идут в трекере боя, дни — при промотке времени. Система даёт готовые (в CP2020 — препараты книги).
- **Экран мастера** — все персонажи кампании одной страницей: состояние, броня, статы, эффекты, деньги, удача.
- **Импорт кампании** из JSON-экспорта: новая кампания со всеми персонажами, предметами и заметками.
- **Проверка принадлежности** — предмет, инвентарь, деньги, заметка и рана из адреса должны принадлежать персонажу.
- **Счётчики** — расширяемый механизм: каждый тип счётчика — стратегия со своей карточкой, полями и действиями; система кампании определяет, какие типы доступны и какие создаются у нового персонажа автоматически.
- **Боевой трекер** — инициатива всем сразу, очередь и раунды, ожидание, а атака, урон и спасброски прямо из строки участника.
- **Кубики** — выражения вида `NdM±K`, быстрые кнопки, лог бросков кампании с игровой датой.
- **Проверки** — модификатор против сложности по правилам системы (по умолчанию d20); противопоставленная проверка навыка против персонажа кампании или противника без листа.
- **Оружие** — предмет с кодом оружия из книги: тип, точность, скрытность, доступность, урон, патрон, магазин, ROF, надёжность, дальность. Справочник на 78 образцов добавляет готовое оружие в инвентарь.
- **Патроны и магазины** — коробки патронов по калибрам, обычные и бронебойные, с ценами из книги. Магазины снаряжаются патронами, оружие перезаряжается магазинами, у каждого свой заряд; есть расширенные магазины и барабаны со штрафами. Револьверы и луки заряжаются напрямую.
- **Навыки и роли** — каталог задаёт система; вкладка появляется, только если у системы есть навыки.
- **Экспорт кампании** в JSON.
- **Приглашение игроков** — на странице кампании у мастера QR-код и ссылка по адресу ноутбука в локальной сети: игрок наводит камеру телефона, вводит логин и пароль («Я новый игрок» — без повтора пароля) и нажимает «Это я» у свободного персонажа или создаёт своего по правилам.
- **«Мой ход» на телефоне игрока** — в бою сверху свой персонаж: «Ваш ход» или сколько ждать, оружие и «Закончить ход»; остальная очередь свёрнута. Подошла очередь — телефон вибрирует (и пищит, если включить звук), экран обновляется сам.
- **Заготовки боя (сцены)** — мастер заранее собирает бой: карта, NPC по шаблону или из кампании, кто в засаде. За столом «▶ Начать» — одно нажатие: NPC создаются, фишки встают в зоны старта карты, инициатива бросается.
- **Запросы бросков и групповая проверка** — мастер просит «Внимательность 15» у одного или у всех: у игрока на телефоне карточка с одной кнопкой «🎲 Бросить», NPC бросаются сразу, итог группы — одной строкой в ленте.
- **Скрытые броски мастера** — «🙈» у броска и проверки: игроки их не видят, мастер может показать всем.
- **Даунтайм одной формой** — «прошла неделя»: кто работал (зарплата по роли), кого лечит какой медик, траты и лечение — одно нажатие, итог по каждому персонажу с отменой.
- **Справка правил под рукой** — «📖 Правила» с любой страницы кампании: сложности, дальность, модификаторы атаки, действия в раунде, порядок урона, лечение и фамблы со страницами книги.
- **Лист на печать и в PDF** — «🖨 Печать»: статы, броня, навыки, оружие со всеми полями, трек здоровья для карандаша на одном листе A4; мастеру — все персонажи сразу.
- **Отмена последнего действия** — после урона, выстрела, покупки, хода боя или промотки времени внизу экрана «↶ Отменить»: кампания возвращается в состояние до действия одним нажатием (последние 20 действий, по очереди с последнего). Отменить может тот, кто сделал, или мастер; кнопка есть и в ленте чата.

### Cyberpunk 2020

- **Статы** — все 9 характеристик, штрафы REF/INT/COOL от ран, человечность и EMP, производные (бег, прыжок, переноска, BTM, спасбросок).
- **Броня** — предметы из таблицы книги надеваются и снимаются: до трёх слоёв на зону, жёсткий один, общий SP по таблице пропорциональной брони, штраф EV к REF. Износ при пробитии остаётся на предмете, есть ремонт.
- **Атака оружием** — с листа: цель из кампании или без листа, расстояние даёт сложность, цель и расстояние запоминаются для оружия, расстояние выбирается одним нажатием, модификаторы FNFF только подходящие оружию; попадание сразу меняет здоровье и броню цели, весь расчёт виден шагами. Очередь, автоогонь, подавляющий огонь, заклинивание по надёжности; дробовик теряет кубики с расстоянием и бьёт пятном.
- **NPC** — отдельный блок на странице кампании: быстрое создание по шаблонам (бандит, коп, корп-охрана, бустер, соло-наёмник) с бросками по книге, сразу несколько, копии и удаление. В выборе цели NPC отделены от игроков.
- **Метание и взрывчатка** — гранаты по видам, нож и сюрикен, C-6 и мины: дальность от BODY, расход количеством, урон по зоне. При промахе заряд отклоняется по таблице гранат: кто и так остался в зоне, уже отмечен, мастеру достаточно подтвердить. Заряд на месте подрывается без броска.
- **Ближний бой** — встречный бросок, защита бросается сама лучшим навыком цели, прибавка к урону от BODY, клинки и моно-лезвия против брони, рукопашная с захватом, броском, удушением и подсечкой, ключевые приёмы боевых искусств, уклонение и парирование.
- **Киберware** — весь справочник книги, установка с потерей человечности и хирургией, эффекты на BODY, инициативу и броню, кибероружие в бою, киберконечности с прочностью и опциями, чипы навыков с обкаткой, репутация и Facedown в трекере, предупреждения киберпсихоза и терапия. На листе — плотный блок фишек, а не список строк.
- **Укрытие** — стена, дверь или машина выбираются прямо в диалоге атаки, SP складывается с бронёй по таблице книги.
- **Особые заряды** — ракетница, РПГ и огнемёт бьют по площади, заряд берётся из запаса; гранатомёт заряжается любой гранатой; пули к дробовику; пластид, TNT, молотов, клеймор, газы по таблице книги. Зажигательная граната и огнемёт догорают в начале следующих раундов боя, оглушающая даёт спасбросок с −5, ослепляющая и звуковая висят на участнике 4 раунда, ослеплённому штраф к атаке уже отмечен в диалоге.
- **Здоровье по правилам Friday Night Firefight** — урон по зоне с учётом брони (AP, обход брони), удвоение в голову, BTM, потеря конечностей, уровни смертельности, спасброски от оглушения и смерти, трата Удачи на важный бросок, стабилизация и лечение броском медика (First Aid, Medical Tech, Speedheal), без лечения раны воспаляются; пошаговый расчёт урона показывается после каждого попадания.
- **d10 с критом** для бросков и проверок: на 10 — дополнительный кубик.
- **Навыки и роли** — навыки книги по статам, 10 ролей со спецспособностями (новая роль открывается на 4 уровне спецспособности текущей), боевые искусства по стилям, языки по семьям, свои навыки (экспертиза, свой стиль); проверка `стат + навык + 1d10` с учётом штрафов от ран и таблицы фамблов.
- **Очки улучшения** — прокачка навыков и уровней ролей за IP: цена следующего уровня видна в каждой строке.
- **Препараты** — 9 наркотиков книги: «Принять» списывает дозу и вешает эффект со сроком; Speedheal ускоряет лечение. Несмертельные газы (слезоточивый, тошнота, галлюциноген, снотворный) дают спасбросок и штраф на лист каждой цели.
- **Мастер и игроки** — вход по логину и паролю. Кто создал кампанию — её мастер и видит всё; игроку мастер отдаёт персонажа по логину, и игрок видит свой лист, бой, карту и чат. Первый зарегистрированный становится мастером уже существующих кампаний.
- **Чат кампании** — сообщения игроков и мастера в одной ленте с бросками, на странице кампании и в бою; другие устройства видят новое опросом.
- **Журнал боя** — одна запись на действие: кто, чем, по кому, бросок против сложности, попал или нет, пробил ли броню, сколько урона и куда, оглушён ли, расчёт по шагам. Бросок «катится» меньше секунды — ждёшь и радуешься, но стол не стоит.
- **Бой — карта во весь экран**: сверху кто ходит и очередь каруселью, слева инструменты карты, справа стол (чат, броски), очередь и инструменты мастера, снизу действия хода. **Туман для игроков**: игрок видит только тех врагов, кого видят его персонажи, остальные в очереди — «?». Линейка, правка мастера (урон, инициатива, убрать) — в меню фишки. **Два режима мастера**: «👁 Бог» (любые фишки, без лимита бега, расстановка, правка карты) и «👹 За NPC» — мастер ходит только своими NPC и по правилам бега, фишку игрока не сдвинуть даже запросом.
- **Боевая карта** — фишки на клетках: перетаскивание, досягаемость бега, поле видимости выбранной фишки (за стенами — тень), видна ли цель целиком, частично или только вслепую сквозь стену, укрытие, кто на линии огня и хватает ли дальности оружия, атака с поля в тот же диалог (цель, расстояние, укрытие, кто в зоне взрыва — сами), двери нажатием, указатели для всех; другие устройства видят изменения опросом. Редактор: комнаты, стены, двери, окна, предметы с поворотом, ряды и россыпь, зоны старта, выделение, отмена, автосохранение, подложка с калибровкой; генератор улицы, бара, склада, парковки, коридоров и крыш и три большие готовые локации — перекрёсток, порт и этаж корпоративного офиса. **Текстовые карты** ([формат](docs/map-format.md)): карту можно нарисовать символами в текстовом редакторе, загрузить, выгрузить обратно; файлы в `resources/maps/` становятся шаблонами (пример — ночной клуб). **Проверка карты** «🧭» по [правилам хорошей боевой карты](docs/map-design.md): несколько путей без одного узкого места, укрытие в полуходе, нет простреливаемых насквозь линий, дистанция в ходах; агентская инструкция по созданию и переносу карт с картинки — `.claude/skills/battle-map/SKILL.md`.
- **Транспорт** — машины с SDP и SP: бросок контроля по манёвру и скорости, таблица потери контроля, урон в SDP через SP, таран по массе; машину можно выбрать целью в диалоге атаки — стрельба и взрыв бьют в SDP без бросков зоны.
- **Нетраннинг** — кибердеки (память, скорость, Data Wall, улучшения за деньги) и 71 программа книги; программы загружаются в деку по памяти; инициатива в Сети, утилиты и бой программами против нетраннера с уроном и эффектами (Hellbolt, Stun, Brainwipe…).
- **Удача везде** — в проверках, атаках, спасбросках, Facedown и медпомощи. Автоогонь делится между несколькими целями, большой магазин клинит чаще, хирургия кибера списывается с денег, рукопашная — и с листа.

## Стек

- **Java 24**, **Spring Boot 3.5** — Web MVC, Data JPA, Validation
- **ZXing** — QR-код приглашения, рисуется на сервере в SVG
- **Thymeleaf** — серверный рендеринг; один CSS и один JS без фреймворков, страницы обновляются без перезагрузки, тёмная тема
- **PostgreSQL 17** в Docker, схема — миграциями **Flyway**
- Тесты: **JUnit 5**, Spring Boot Test, MockMvc, Mockito, **H2** в режиме PostgreSQL
- Lombok, Maven Wrapper

## Быстрый старт

### Требования

- **JDK 24+**
- **Docker** (Docker Desktop на Windows/macOS) — для базы данных

### Запуск

```bash
git clone git@github.com:Andezahr/Charka.git
cd Charka
./mvnw spring-boot:run
```

Приложение откроется на <http://localhost:8080>. База поднимается автоматически из [`compose.yaml`](compose.yaml) (через `spring-boot-docker-compose`) — нужен только запущенный Docker.

При первом старте, если кампаний нет, создаётся демо-кампания **«Последний шанс»** (Cyberpunk 2020) с двумя персонажами.

Вход по логину и паролю: откройте `/register` — первый зарегистрированный становится мастером демо-кампании и всех кампаний без мастера. На сервере задайте свой ключ cookie «запомнить меня» переменной `REMEMBER_KEY`; `CHARKA_SECURITY=false` выключает вход (только для локальной игры одного человека).

> На Windows вместо `./mvnw` используйте `mvnw.cmd`.

### База данных

| Параметр | Значение по умолчанию | Переменная окружения |
|---|---|---|
| URL | `jdbc:postgresql://localhost:5433/charka` | `DB_URL` |
| Пользователь | `charka` | `DB_USER` |
| Пароль | `charka_dev_pw` | `DB_PASSWORD` |

Порт **5433** выбран, чтобы не конфликтовать с локально установленным PostgreSQL. Данные хранятся в Docker-томе `charka-pgdata`. Поднять базу вручную:

```bash
docker compose up -d
```

Схема меняется **только миграциями** в `src/main/resources/db/migration/V<n>__*.sql`; Hibernate работает в режиме `validate`.

### Тесты

```bash
./mvnw test
```

Живой PostgreSQL не нужен — тесты используют H2 в режиме совместимости с PostgreSQL на тех же миграциях.

### Docker-образ

```bash
./mvnw spring-boot:build-image
```

Соберёт образ `charka/app:latest`.

```
src/main/java/app/charka
├── model/        JPA-сущности: Campaign, Character, Wound, Inventory, Item, Money, Note, Counter…
├── repository/   Spring Data репозитории
├── service/      бизнес-логика (кампании, время, счётчики, заметки…); impl/ — реализации интерфейсов сервисов
├── controller/   MVC-контроллеры страниц
├── api/          REST: экспорт кампании в JSON
├── dice/         разбор выражений NdM±K, броски, лог бросков
├── check/        проверки: запрос, результат, резолвер по правилам системы
├── skill/        навыки и роль персонажа, проверка навыка
├── system/       контракт GameSystem и реестр систем
│   └── cp2020/   правила Cyberpunk 2020: статы, броня, здоровье, кубики, проверки, навыки, фамблы
├── dto/          DTO счётчиков
└── exception/    404/400/500 для страниц и API

src/main/resources
├── templates/    Thymeleaf-шаблоны (страницы, фрагменты, карточки счётчиков)
├── static/       app.css, app.js
└── db/migration/ миграции Flyway
```

### Доменная модель

```
Campaign (система, дата начала, текущая дата)
 ├─ Chronicle*   — прошедшие периоды
 ├─ RollLog*     — лог бросков
 └─ Character*
     ├─ Wound*
     ├─ Inventory* └─ Item*
     ├─ Money*     — журнал операций
     ├─ Note*      ←→ NoteCategory
     └─ Counter*   — значение + атрибуты, поведение задаёт стратегия типа
```

### Как добавить игровую систему

Правила системы живут в собственном пакете (`system/<код>/`) и подключаются к ядру через интерфейсы:

1. Реализовать `GameSystem` (код, название, валюта, счётчики по умолчанию, резолвер проверок, реакция на течение времени) и сделать его Spring-бином — `GameSystemRegistry` подхватит его автоматически.
2. Добавить стратегии счётчиков (`CounterStrategy`) с `getSystems()`, возвращающим код системы, и шаблоны их карточек в `templates/counters/types/`.
3. Таблицы и формулы — в классе `*Rules` системы, без состояния и с юнит-тестами.

Подробности архитектуры и соглашения — в [`CLAUDE.md`](CLAUDE.md) и разделе 2 [`TODO.md`](TODO.md).

## Основные маршруты

| Путь | Страница / действие |
|---|---|
| `/` | список кампаний и персонажей |
| `/campaign/{id}` | кампания: персонажи, хроника, промотка времени, кубики |
| `/character/{id}` | лист персонажа: состояние, оружие, носимое, деньги кратко, частые навыки |
| `/character/{id}/gear` | снаряжение: все инвентари, вживлённое, журнал денег, регулярные траты |
| `/character/{id}/skills` | навыки, роль, проверки навыков |
| `/character/{id}/notes/` | заметки и контакты |
| `/campaign/{id}/gm` | экран мастера |
| `/api/campaigns/{id}/download` | экспорт кампании в JSON; `/campaigns/import` — импорт |

Полная таблица маршрутов — в [`CLAUDE.md`](CLAUDE.md#http-маршруты).
